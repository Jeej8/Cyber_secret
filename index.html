What did you learn?

The invitation code was hidden inside an HTML comment in the webpage's source code. HTML comments are visible to anyone who inspects that source. Sensitive information, such as passwords and secret codes, should never be stored in client-side HTML. It should be protected on the server using appropriate access controls.
